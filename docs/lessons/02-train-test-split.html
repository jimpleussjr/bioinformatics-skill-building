Lesson 2: Train/Test Splitting and Honest Evaluation

Introduction to the Domain

A model that memorizes the data it was trained on is useless in practice. Train/test splitting is the simplest way to estimate how a model will perform on new patients. Done wrong (leakage, imbalance, no stratification), it gives misleading optimism. This lesson is methodological but uses a health dataset.

Research Question

How do we split data so that our evaluation reflects real-world performance, and what goes wrong when we do it carelessly?

Open-Source Dataset

Pima Indians Diabetes Database (UCI / Kaggle) — reused here for methodology.

  • Link: https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database
  • Size: 768 rows, 8 features + outcome.
  • Outcome: Outcome (0/1).
  • Notes: class imbalance (~35% positive); zeros encode missing values.

Practical Exercise

Model to explore

A simple logistic regression used as a vehicle to study splitting strategies (random split, stratified split, cross-validation).

Health Domains & Machine Learning: A Skill-Building Course

Welcome

This site hosts a self-paced series of 17 lessons. Each lesson pairs a distinct health domain with a distinct statistical or machine-learning model, walking you from domain context to a runnable practical exercise. Every lesson now includes starter code with THINK markers and a Deliverables section (a figure, a table, and written questions).

Every lesson follows the same scaffold:

  1. Introduction to the Domain — what the problem is and why it matters.
  2. Research Question — a concrete, answerable question.
  3. Open-Source Dataset — a publicly available data source, with discussion and a link.
  4. Practical Exercise — which model/framework to explore, starter code, suggested AI prompts, and extension ideas.
  5. Deliverables — a figure, a table, and questions to answer.

How to use this course

  • Work the lessons in order the first time through; later you can jump to a domain or model of interest.
  • Do not just run the starter code. Lines flagged # THINK require you to write a one-sentence justification before executing.
  • Each exercise is designed to be completed in a Jupyter notebook or RStudio session.
  • Use the suggested AI prompts to have a language model explain, debug, or extend your analysis — treat the AI as a tutor, not an oracle.
  • Datasets are linked, not vendored: download them yourself so you control versioning.

## Welcome

This site hosts a self-paced series of **17 lessons**. Each lesson pairs a distinct **health domain** with a distinct **statistical or machine-learning model**, walking you from domain context to a runnable practical exercise. Every lesson now includes **starter code with THINK markers** and a **Deliverables** section (a figure, a table, and written questions).

Every lesson follows the same scaffold:

1. **Introduction to the Domain** — what the problem is and why it matters.
2. **Research Question** — a concrete, answerable question.
3. **Open-Source Dataset** — a publicly available data source, with discussion and a link.
4. **Practical Exercise** — which model/framework to explore, starter code, suggested AI prompts, and extension ideas.
5. **Deliverables** — a figure, a table, and questions to answer.

## How to use this course

- Work the lessons **in order** the first time through; later you can jump to a domain or model of interest.
- **Do not just run the starter code.** Lines flagged `# THINK` require you to write a one-sentence justification before executing.
- Each exercise is designed to be completed in a Jupyter notebook or RStudio session.
- Use the suggested **AI prompts** to have a language model explain, debug, or extend your analysis — treat the AI as a tutor, not an oracle.
- Datasets are linked, not vendored: download them yourself so you control versioning.
